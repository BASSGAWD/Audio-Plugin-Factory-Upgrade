1. Capture the exact error.
2. Reproduce it.
3. Identify the failing subsystem.
4. Inspect relevant code.
5. Form a hypothesis.
6. Make the smallest justified change.
7. Rebuild.
8. Run the relevant test.
9. Run regression tests.
10. Continue only when evidence supports the fix.

DO NOT repeatedly make random changes.
